Trazer do Sistema Anterior

Consulte os dispositivos de um cliente no sistema antigo (monitorando), reaponte os rastreadores para a AgilLock e envie o acesso ao cliente pelo WhatsApp.
Reapontar Histórico

ETAPA 1 Consultar cliente no sistema anterior

Casa pelo nome (ignora acento/maiúsculas) e aceita nome parcial. Nada é enviado nesta etapa — é só consulta.

Opções avançadas
15 = rastreadores GT06 reais. 0 = todos.

Resultado da consulta

IMEIVeículoStatus ClienteExiste aqui
0 selecionado(s) de 0. Selecionar todos · limpar

ETAPA 2 Enviar comando aos dispositivos selecionados

Por padrão envia o comando de troca de servidor (traz o rastreador para a AgilLock). Você também pode enviar um comando personalizado para um, vários ou todos os dispositivos selecionados do cliente.

  
Comando: SERVER,0,72.62.13.73,5023,0#
Use ${dispositivo} para inserir o IMEI de cada equipamento no comando (ex: Suntech).
